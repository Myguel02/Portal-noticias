# 📰 Portal de Notícias

Projeto desenvolvido em React + TypeScript como parte da disciplina.

---

## 🚀 Tecnologias utilizadas

- React
- TypeScript
- React Router
- CSS

---

## 📦 Como executar o projeto

```bash
npm install
npm run dev
```

---

## 📌 Funcionalidades

- Página inicial com notícias
- Cadastro de usuário
- Login com acesso rápido
- Recuperação de senha
- Navegação entre páginas

---

## 👤 Perfis do sistema

- Leitor
- Autor
- Editor
- SuperAdmin

---

## 💾 Armazenamento

Os dados são salvos utilizando **localStorage** (simulação de banco de dados).
